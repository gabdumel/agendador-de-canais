Agendador de Canais

Ferramenta pessoal e privada para agendar o envio dos próprios vídeos aos próprios canais do YouTube.

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube.

O que faz

  • Envia vídeos já finalizados pelo próprio criador para os canais dele, como privados com data de publicação agendada.
  • Define título, descrição, tags, legenda e thumbnail escritos pelo próprio criador.
  • Roda somente no computador do proprietário. Não é oferecido ao público e não coleta dados de espectadores nem de outros canais.

English

Agendador de Canais is a private, personal tool that schedules uploads of the owner's own finished videos to the owner's own YouTube channels. It uses YouTube API Services and is not offered to the public.
